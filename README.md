# Smart Contact Manager

A full-stack web application developed using Spring Boot that allows users to securely manage contacts with authentication and CRUD functionality.

---

## Features

- User Authentication & Authorization using Spring Security
- Add, Update, Delete Contacts
- Responsive UI using Bootstrap
- Secure Login & Registration
- RESTful API Integration
- Database Management with MySQL
- MVC Architecture Implementation

---
